# Hill Weather

Hiking forecasts for Irish hills from [Open-Meteo](https://open-meteo.com/): a go/no-go rating, the best walking window before sunset, hour-by-hour conditions on the tops and a pack list.

Open it at https://mannionbrian4-maker.github.io/hill-weather/ and add it to your home screen.

Weather data by Open-Meteo.com (CC BY 4.0).
